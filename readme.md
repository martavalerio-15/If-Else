# Marta Valério_ If/Else

Para o exercício If/Else, criei um canvas “dividido” em 6 secções (3 em cima e 3 em baixo). Através do uso do if, else ao mover o rato por essas secções a cor do fundo muda consoante o local do cursor. Adicionei ainda um círculo que segue o rato, usei um if caso o rato fosse premido (if (mouseIsPressed)) esse círculo aumenta-se de tamanho (250), caso contrário, mantém o tamanho pequeno (50).
